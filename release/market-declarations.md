# Cycle Pair 마켓 신고 준비

2026-10-25 갱신. 대상은 `com.seorilabs.cyclepair`이며 Android 1.1.1(1000108)은 내부 테스터에게 제공 중이다. 신규 Plus 판매는 꺼져 있다. 이 문서는 신고 입력 기준과 확인한 저장 상태를 기록한다. 마켓별 현재 후보, 심사와 공개는 별도 운영 근거를 따른다.

## Google Play

| 항목 | 준비 답안 | 근거와 남은 확인 |
|---|---|---|
| 건강 기능 | Period tracking | 2026-10-25 Console 저장. 개인 주기, 증상과 컨디션 기록, 주기와 가임 시기 참고 표시이며 의료기기, 진단과 치료, 피임 기능으로 신고하지 않는다. |
| 건강 기능 추가 설명 | 주기와 컨디션을 개인적으로 기록하고, 사용자가 켠 항목만 연결한 한 사람에게 공유한다. 추정치는 참고용이며 의료, 피임과 임신 가능성 판단에 사용하지 않는다. 의료 조언이 필요하면 의료 전문가와 상담한다. | 한국어와 영어 마켓 설명 및 앱의 고지와 대조한다. |

| 광고 | 없음 | 현재 후보의 광고 식별자 수집 플래그는 꺼져 있다. 활성 구버전까지 동일하다고 판정하지 않는다. |

| 정부 앱 | 아님 | 2026-10-25 Console 저장. 정부에서 또는 정부를 대신해 개발한 앱이 아니다. |
| 금융 기능 | 없음 | 2026-10-25 Console 저장. 금융 서비스와 보상 자산을 제공하지 않는다. |
| 콘텐츠 등급 | 비게임 앱, 두 사람의 사적 콘텐츠와 상호작용 있음 | 2026-10-25 IARC 설문지 저장. 초대된 사람만 상호작용하며 공개 채팅과 피드가 없다. 사용자 메모와 공동 일정, 두 고정 메시지가 있다. 계산된 콘텐츠 등급은 서비스의 최소 이용 연령과 별개다. |

| 계정과 삭제 | 이메일 계정 및 게스트 제공. 앱 내 영구 삭제와 웹 삭제 요청 경로 있음 | `https://www.seorilabs.com/apps/cycle-pair/account-deletion/`. 최종 운영 빌드의 접근과 삭제 동작을 확인한다. |
| 앱 접근 안내 | 심사용 계정 두 개 등록, 전체 접근 검증 미완료 | 운영 Firebase 계정 생성과 REST 로그인은 확인했다. 실제 출시 앱의 로그인과 확장 기능 접근은 미확인이다. 검증되지 않은 전체 접근 확인란을 선택하지 않았고 안내 저장도 완료되지 않았다. 비밀번호는 이 문서에 넣지 않는다. |

최종 Data safety 답변은 현재 배포 중인 모든 버전을 포함해야 한다. 기존 내부 테스트 1.0.9가 교체 또는 비활성화되기 전에는 새 후보의 광고 수집 설정만으로 전체 배포본을 판단하지 않는다. 기존 트랙과 실제 버전은 다시 읽어야 한다.

현재 Console 양식은 계정 생성 방식과 두 삭제 URL을 요구한다. 이메일과 비밀번호, 익명 게스트 가입을 신고한다. [계정 유지와 개별 기록 삭제 안내](https://www.seorilabs.com/apps/cycle-pair/account-deletion/#delete-data-without-account)와 영어 안내를 게시했고 HTTP 200 및 새 절차를 확인했다. 계정 전체 삭제 링크와 목적을 구분한다. 개별 기록을 삭제해도 설정의 주기 시작 및 종료 기준은 유지된다.

사용자가 지정한 소유 계정의 앱을 대상으로 한다. 입력 전 개발자 계정의 이름, 유형과 ID, 패키지 소유권을 실시간으로 확인한다. 이 문서는 계정 확인을 대신하지 않는다.

App Review 안내 초안: 게스트로 혼자 기록할 수 있으며, 이메일 계정으로 전환해 기록을 복구할 수 있다. 두 시험 계정으로 초대를 수락한 뒤 공유할 항목을 각각 고른다. 기본값은 모두 비공개다. 원본은 작성자만 읽고 상대는 선택한 사본만 본다. 공유를 끄거나 연결을 해제할 수 있다. 설정에서 진단 선택, 데이터 내보내기와 영구 삭제를 제공한다. 의료기기, 진단과 치료, 피임이나 임신 가능성 판단용 앱이 아니다. Plus 신규 판매는 제공하지 않는다.

## 이미지와 제출 전 확인

등록 이미지는 원본 RN 화면의 개발 브라우저 실행에서 새로 캡처한다. 합성 자료만 사용하며 운영 계정이나 인증 화면을 촬영하지 않는다. Play와 App Store는 별도 크기와 언어별 목록으로 관리한다. 이 이미지로 네이티브 SDK, OS 권한, 키보드와 안전 영역 동작을 통과로 판정하지 않는다. App Store 제출 전 실제 iOS 화면과의 일치 여부를 확인한다.

개발 검수 완료 후 네이티브 보안 저장소, 실제 플랫폼 인증과 알림 권한 및 FCM/APNs 중 개발 환경으로 확인할 수 없는 필수 항목을 구체적으로 좁혀 별도 기기 승인을 요청한다. 개발 환경 전체 흐름을 기기에서 그대로 반복하도록 요청하지 않는다.
