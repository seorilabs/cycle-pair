# 1.2.0 등록 정보와 이미지

출시 후보는 `v1.2.0`, 코드 `fc60c9e7c8e875104388ef03a4c6c27176554726`이다. Android versionCode는 `1000109`, Apple build number는 `1002000`이며 태그의 발급 기록을 따른다. 이 문서와 등록 파일 변경은 후보 코드를 바꾸지 않는다.

한국어와 영어 문구는 이메일 또는 게스트 시작, 단계별 설정, 실제 기록 기반 시각화, 직접 켠 항목만 공유하는 동작을 설명한다. 무료, 광고 없음과 인앱결제 없음을 유지한다. 의료 효능이나 10년 데이터 보유를 주장하지 않는다. 개인정보 수집 분류와 가격, 배포 국가를 바꾸지 않았다.

[등록 이미지 목록](../../release/registration-assets.json)의 26개 원본은 같은 후보의 실제 RN 개발 화면과 합성 기록을 사용한다. 마켓별 시작, 기록, 홈, 달력 순서를 맞췄고 Play 태블릿 화면도 준비했다. 네이티브나 실기기 캡처를 뜻하지 않는다. 구형 공유 화면 파일은 새 목록으로 대체해 삭제했다.

독립 화면 검수는 기존 실패를 보존한 1회차부터 5회차까지 기록했다. 승인된 5회차의 기능과 사용성 10개가 모두 통과했고, 개발 환경 전체 회귀 793개도 통과했다. 큰 글자 달력과 영어 공유 코드 입력을 실제 실행했다. Google Play와 App Store의 중앙 빌드 전 L3 검사도 통과했다. [태그 Release](https://github.com/seorilabs/cycle-pair/releases/tag/v1.2.0)에 검증 근거와 마켓별 출시노트를 보관한다.

App Store의 편집 버전을 1.2.0으로 바꾸고 한국어와 영어 문구, iPhone 이미지 8개를 저장했다. 이미지 처리 COMPLETE와 처리된 파일의 픽셀 일치를 확인했다. 오래된 iPad 이미지 연결 3개는 백업 뒤 제거했다. 기존 빌드 15의 연결만 해제했으며 원본 빌드는 보존했다. 새 빌드 연결과 심사 제출은 아직 하지 않았다.

iOS 빌드 실행 [40254674616](https://github.com/seorilabs/cycle-pair/actions/runs/40254674616)은 앱 Release 타깃에 `PROVISIONING_PROFILE_SPECIFIER`가 없다는 검사에서 종료됐다. 설치된 기존 프로파일은 `Cycle Pair App Store 2026-07-23`이며 아카이브와 업로드는 실행되지 않았다. 서명 설정과 현재 배포 경로의 불일치를 해결하려면 별도 변경과 새 불변 태그가 필요하다. 키, 인증서와 파이프라인은 변경하지 않았다.

Google Play의 API 저장 두 번은 완료되지 않았다. 첫 편집은 만료 전 삭제됐고, 두 번째는 검토 없이 저장하는 옵션이 거절됐다. 두 편집을 종료한 뒤 문구와 이미지 해시, 트랙이 기존 상태와 같음을 확인했다. 콘솔에서 두 언어의 문구를 저장했다. 트랙은 기존 internal 1000108 completed와 같고 production은 비어 있다. 영어 그래픽의 기본 이미지 상속을 원본의 명시적 연결로 고친 뒤 총 18개의 해시와 순서, 처리된 이미지의 픽셀이 모두 정본과 일치함을 확인했다. Console의 저장만 수행했으며 심사 전송 버튼을 누르지 않았다.

실제 실행 원본은 NAS1dual의 `cycle-pair/2026-10-26/fc60c9e7c8e875104388ef03a4c6c27176554726/ui-independent-round5-100044-41898e`에 보관했다. 검증 목록 SHA256은 `0a955216ad0236bd64923b5f4f05f9ad54911a3aa16593a974e7ce1aaaa46097`이다. 등록 정보 변경 전 원본도 같은 후보 아래 `before-market-metadata-101030-a7f297`에 보관했고 검증 목록 SHA256은 `b5e39b54330159f7d481f9967ce3ea3cb0ce778b989349a3fdd92933368fc17f`다.

Android 1.2.0(1000109)은 [빌드와 업로드 실행](https://github.com/seorilabs/cycle-pair/actions/runs/40256647671)을 마쳤고 Publisher API에서 internal completed를 확인했다. AAB SHA256 `d562ddfb0b1cea992d0f7ba1ae892d0f891ec11f517c6ef43a69844893f735e0`은 CI와 같다. Play가 생성한 APK도 패키지와 버전, 서명을 검증했으며 결제 권한이 없다. 두 언어 출시노트와 등록 이미지도 업로드 후 유지됐다.

중앙 before-release 검사는 두 마켓 모두 통과했다. 이는 승인된 개발 범위의 검사이며 실제 네이티브 실행을 증명하지 않는다. 기존 네이티브 출시 설계에 남긴 운영 인증, 보안 저장소와 OS 알림 항목은 별도 상태다. Firebase의 기존 Android 앱은 ACTIVE지만 인증서 SHA 등록이 0개다. 현재 Play 배포 인증서는 읽기 전용으로 확인했으며 새 키 발급이나 강제 검사 변경은 하지 않았다.

현재 공개 단계와 남은 조건은 [출시 원장](../../release/market-launch-state.json)을 따른다. iOS 빌드는 서명 연결 복구와 새 버전 선택 대기이며 실제 네이티브 검증, 심사, 승인과 공개는 완료하지 않았다.
