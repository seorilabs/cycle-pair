# 무료 첫 출시와 이후 판단

2026-10-25 사용자가 첫 출시 범위를 **무료, 광고 없음, 인앱결제 없음**으로 정했다. 구독의 가치가 확인되기 전에는 판매를 시작하지 않고, 출시 후 사용과 쌓인 기록을 보며 다음 제품 방향을 정한다.

## 이번 출시

- Google Play와 App Store에 기존 기록, 기본 예측, 한 사람과의 선택 공유, 공동 일정, 내보내기와 계정 삭제 기능을 출시한다. iOS는 기존 결정대로 iPhone만 지원한다.
- 구독 구매, 무료 체험과 구독 업셀, 지원코드로 유료 혜택을 지급하는 기능을 추가하지 않는다. 주간 리포트와 케어플랜 제안도 이번 출시의 구현 또는 심사 조건이 아니다.
- 현재 마켓 설정의 구독 상품 목록은 비워 두고 신규 판매 비활성을 유지한다. 과거에 등록한 스토어 상품과 구매 자료의 삭제나 환불을 수행했다는 뜻은 아니다. 실제 Console의 상품 및 제출 연결 상태는 별도 확인한다.
- 다운로드와 실제 앱 기능은 무료로 설명한다. 장기 데이터가 있는 것처럼 표현하거나 향후 유료 기능을 현재 기능으로 광고하지 않는다. 영구 무료를 약속하는 문구는 사용하지 않는다.
- 기존 무료 앱 후보와 태그는 보존한다. 현재 Android 1.1.1과 iOS 1.1.0 후보는 구매 화면과 실제 결제 SDK를 연결하지 않는다. 이번 메타데이터 정리만으로 새 앱 버전과 빌드를 만들지 않는다.

사용자의 이 지시가 이번 범위의 근거다. 기존 네이티브 출시 설계의 개발 검증과 두 마켓 공개 목표는 유지하고, 미승인 구독 설계와 별도 1.1.2 제안은 보류한다. 새 화면을 구현하지 않으므로 독립 화면 검수 회차를 추가하거나 이전 결과를 새 후보 결과로 다시 쓰지 않는다.

## 신고와 검증

출시 진입점의 구매 SDK 미연결 검사와 현재 Android 서명 AAB의 Billing 및 광고 식별자 권한 부재를 확인한다. 개발 검사, 빌드와 내부 배포, 실제 플랫폼 동작, 심사 제출과 공개는 따로 기록한다.

Google Play 데이터 보안과 Apple App Privacy의 구매 내역 수집은 이번 무료 후보에서 제외한 답안으로 준비한다. 기존 다른 수집 항목, 동의, 사용자 연결과 추적 없음 기준은 유지한다. 이전 10개 분류 임시 저장 결과를 새 9개 분류의 Console 저장 완료로 사용하지 않는다. 사용자 검토와 실제 저장 및 재조회는 별도 단계다.

기존 심사 계정은 별도 유료 권한을 요구하지 않는다. 실제 인증과 원격 알림 중 개발 환경에서 대체할 수 없는 필수 항목은 구체적인 도구와 범위를 준비하고 별도 기기 사용 승인을 받아 확인한다. 실제 결제와 구매 복원은 이 무료 출시의 요구사항이 아니다.

## 출시 후 확인할 것

기존 진단 동의와 비민감 이벤트를 사용하며 새 건강정보와 메모 원문 수집을 추가하지 않는다. 수치에는 동의한 관측 집단의 크기, 기간과 수집 확인 상태를 함께 적는다. 수집이 확인되지 않으면 0으로 표시하지 않는다.

| 질문 | 볼 지표 |
|---|---|
| 처음 설치한 사람이 기록을 남기는가 | 온보딩 완료, 첫 기록 완료, 동기화 성공과 대기 |
| 혼자 기록한 뒤 계속 사용하는가 | D1과 D7 재방문, 주간 기록한 날짜 수 |
| 두 사람이 실제로 연결하고 활용하는가 | 초대 생성, 연결 완료, 공유 설정, 파트너 화면 열기 |
| 기본 경험이 안정적인가 | 저장과 동기화 오류, 인증 오류, 충돌과 지원 문의 |
| 운영을 지속할 수 있는가 | 확인 가능한 인프라 비용과 활성 사용자 규모 |

첫 점검은 출시 후 4주를 기준으로 잡되, 충분히 관측한 D7 집단과 표본 수가 없으면 결론을 유보한다. 실제 반복 사용과 문의에서 드러난 문제를 먼저 고친다. 그다음 어떤 기능이 지속적인 가치를 주는지 검증하고 구독, 다른 수익모델 또는 무료 운영 유지를 다시 결정한다. 구독 도입과 가격은 별도 제품 결정이며 자동으로 활성화하지 않는다.
