# Cycle Pair 1.2.1 출시 상태

후보는 `v1.2.1`, 소스 `0360e7a174570818d48f372bead80517a6f73695`다. [서명 복구 PR](https://github.com/seorilabs/cycle-pair/pull/163)을 병합했고, 기존 `v1.2.0`은 유지했다. 기존 공개 앱 서명 인증서의 Firebase 등록과 자격증명 목록 등록, 변경 전후 백업 및 복원 검증을 마쳤다.

최종 후보에서 독립 호스트 검사 795개, 실제 RN 개발 화면 기능 10개와 11시나리오가 통과했다. 이전 R1~R5 원문과 실패 해결 이력을 보존했으며 새 UI 검수 회차는 만들지 않았다. 두 마켓의 중앙 L3 before-build와 before-deploy도 통과했다. 네이티브 실행을 뜻하지 않는다.

운영 함수 23개의 최신 Ready 리비전과 트래픽 100퍼센트, 현재 원본 16개와 컴파일 JavaScript14개를 대조했다. 구독 코드와 모듈은 제외했고, 폐기한 함수 4개는 404다. Rules는 현재 원본과 같으며, 필요한 인덱스 2개는 READY다. 기존 권한과 실행 자원을 유지했고 자료 이전이나 기존 사용자 자료를 직접 수정하는 작업은 하지 않았다. 초기 병렬 배포의 CPU 한도 실패와 순차 복구 기록도 보존했다. 영문 및 한국어 내보내기 안내는 200, 지원하지 않는 언어는 400, 로그인 없는 내보내기 요청은 401을 확인했다.

공개 전에는 Play Integrity 프로젝트 연결에 수반되는 서비스 약관 동의, 네이티브 인증과 보안 저장 복원, 앱 무결성 증명과 실제 FCM 및 APNs 수신, App Check 강제 적용, 현재 정책과 국가 목록 최종 확인이 남아 있다. 기기는 조회하거나 조작하지 않았다. 심사 제출과 공개도 아직 하지 않았다.
