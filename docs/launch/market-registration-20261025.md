## 이미지 정본과 검증

정본은 [등록 이미지 목록](../../release/registration-assets.json)이다. 원본 RN 화면을 개발 환경에서 직접 렌더링한 픽셀을 사용했으며 합성 자료만 담았다. 기기 캡처나 네이티브 SDK 검증의 근거로 사용하지 않는다. 두 언어의 실제 글과 화면을 읽고 의료 효능, 구독 또는 10년 데이터 보유를 주장하는 문구가 없는지 확인했다.

이전에 준비한 20종 중 파트너 화면 4종에는 내부 QA 메모가 있어 등록하지 않았다. 현재 제품 원본은 두 마켓의 스크린샷 12개와 Play 그래픽 2개이며 아이콘은 기존 정본을 유지한다. 구형 등록 이미지 파일은 현재 목록에서 제거했고 Git 이력은 보존했다.

정확한 크기와 PNG, 배경 검증은 등록 이미지 검증기로 수행한다. 공용 Google Play 설정 검증기는 태블릿 이미지를 각 2장 요구하므로 현재 `not-ready` 2건을 반환한다. 이 결과를 통과로 표시하지 않았다. Console은 태블릿 이미지가 없는 휴대전화 등록을 저장했다. 해당 검사와 등록 범위의 차이는 최종 출시 검사 전에 정리해야 한다.
