이 문서는 planning 승인 이후 제품 실행 source of truth다. 한국어 출시 이름은 `사이클 페어 : 내 기분, 주기, 컨디션을 알려요`, 영어 출시 이름은 `Cycle Pair`다. 한국어 앱 내부 UI와 알림에는 짧은 브랜드 `사이클 페어`를 사용한다. Android package name과 iOS bundle ID는 `com.seorilabs.cyclepair`, 단일 Firebase project ID는 `seorilabs-cyclepair-prod`다. AppsInToss 영구 appName은 `cycle-pair`로 승인했으며 Console 등록·readback 전에는 출시 evidence로 인정하지 않는다.

## 제품 약속

주기를 기록하는 사람과 가까운 한 사람이 생리주기와 당일 컨디션을 사용자가 허용한 만큼만 공유하고, 실제로 요청한 도움을 중심으로 함께 대비하도록 돕는다. 의료 진단, 치료, 피임 또는 임신 가능성 판단 도구가 아니다.

## 확정된 MVP 경계

### 포함

- 정확히 두 명으로 구성된 대칭형 Pair
- 사용자당 활성 Pair 하나와 공유 상대 한 명
- Pair 연결 전 본인 전용 기록
- 최근 생리 시작·종료일, 증상, 기분, 에너지, 컨디션, 도움 선호 기록
- 다음 생리 예정일과 신뢰 구간을 참고 정보로 표시
- 필드별 명시적 공유 동의
- 공유된 정보만 담는 partner projection
- 파트너 상태, 사용자 선택 기반 케어 가이드
- 공동 캘린더와 기념일
- 잠금화면에서 건강정보를 드러내지 않는 중립 알림
- 데이터 내보내기, 계정 삭제, Pair 연결 해제
- 무료 기능과 프리미엄 구독을 분리할 수 있는 entitlement 경계
- AppsInToss에서 날짜·자유 텍스트·계정 식별자 없이 컨디션과 도움 선호를 로컬 저장하고 명시적으로 공유하는 최소 slice

### 제외

- 가임기, 배란일, 임신 가능성 또는 피임 관련 표시
- 의료 진단, 치료 또는 효능 보장
- 다중 파트너와 친구 그룹
- 실시간 채팅
- 광고와 건강 데이터 기반 타기팅
- 위치 추적
- 제3자 데이터 판매
- E2E 암호화 구현
- AppsInToss의 Firebase 계정·Pair 동기화·알림·구독 parity

E2E 암호화는 단순 제외가 아니라 MVP 이후 재검토 대상이다. 위협모델과 결정 기록은 [security-threat-model.md](./security-threat-model.md), [ADR-0001](./adr/0001-mvp-e2e-encryption.md)에 둔다.

## 사용자 모델

- Logger와 Companion은 고정 권한 역할이 아니다.
- Member마다 recordsCycles 여부를 독립적으로 가진다.
- 두 Member 모두 자기 기록의 소유자이며 자기 공유 범위를 정한다.
- 초대 수락 전에도 본인 전용 기록은 사용할 수 있다.
- Pair 기능은 양쪽이 연결을 수락한 뒤 활성화된다.
- 한 사용자가 이미 활성 Pair에 속한 경우 새 Pair를 만들거나 세 번째 Member를 추가할 수 없다.

## 화면과 완료 조건

| 화면 | 필수 동작 | MVP 완료 조건 |
| --- | --- | --- |
| 온보딩·로그인 | 비의료 도구와 공유 통제권 설명 | 민감정보 별도 동의 전에는 건강 기록 저장 금지 |
| 초기 설정 | recordsCycles, 최근 생리 시작일, 평균 주기 입력 | 필수값 누락 시 예측 대신 기록만 제공 |
| 초대·수락 | 메인에서 선택적으로 1회성 초대 생성, 명시적 수락 | 연결 없이도 본인 기록 사용, 자기 초대·만료 초대·제3자 연결 차단 |
| 공유 설정 | 필드별 켜기·끄기 | 기본값은 모든 건강 필드 비공개 |
| 홈 | 내 상태와 허용된 파트너 정보 | 가임기·배란기·피임 표현 없음 |
| 기록 | 주기·증상·기분·컨디션·도움 선호 | 로컬 우선 저장 후 동기화 상태 표시 |
| 공동 캘린더 | 공유된 주기 정보와 공동 일정 | 비공개 기록은 캘린더 projection에 없음 |
| 파트너 상세 | 공유된 값과 케어 가이드 | 공유하지 않은 키는 응답 자체에 없음 |
| 설정·구독 | 공유 변경, 연결 해제, 내보내기, 삭제 | 위험 동작 재확인과 결과 상태 제공 |
| 오류·오프라인 | 캐시 표시, 재시도, 충돌 안내 | 오래된 projection임을 명시 |

## 주기 예측 정책

- 날짜는 시간대 없는 ISO 8601 LocalDate 형식 YYYY-MM-DD로 계산한다.
- 현재 core 기준 유효 주기 간격은 15~60일이며 범위 밖 값은 평균에서 제외한다.
- 유효한 완료 주기 간격이 없더라도 사용자가 평균 주기를 직접 입력한 경우에는 표본 0개·low confidence·±7일인 임시 seed 범위만 표시한다. 입력값도 없으면 예측을 생성하지 않는다.
- 유효 간격의 평균으로 다음 생리 예정일을 계산한다.
- 표본 수와 변동성에 따라 low, medium, high 신뢰도를 계산하고 각각 넓이가 다른 신뢰 구간을 표시한다.
- 모든 예측에는 개인차가 있으며 의료 또는 피임 판단에 사용할 수 없다는 안내를 둔다.
- 내부 계산에 ovulatory 상태가 존재하더라도 MVP UI, partner projection, 알림, Analytics에는 노출하지 않는다. menstrual, follicular, luteal 같은 비가임 phase는 사용자가 명시적으로 켠 경우에만 partner projection에 포함할 수 있다.
- 케어 가이드는 추정 주기보다 사용자가 직접 공유한 컨디션과 도움 선호를 우선한다.

## 공유 정책

- 원본 주기·증상·기분·메모는 항상 owner-private이다.
- 공유 설정이 켜진 값만 서버가 별도 projection에 복제한다.
- 공유를 끈 값은 null로 남기지 않고 projection 문서에서 제거한다.
- 기본 공유 설정은 모든 건강 필드 false다.
- 공유 설정은 현재 Pair에만 유효하며 새 Pair 연결 시 이전 동의를 재사용하지 않는다.
- 파트너 클라이언트는 owner-private 문서를 읽을 수 없다.
- Pair 연결 해제 시 파트너의 서버 접근을 즉시 거부하고 projection을 삭제한다.
- 오프라인 상대 기기의 캐시는 다음 동기화 때 사용자 전용 tombstone을 받아 삭제한다.

## 알림 정책

- 알림은 opt-in이며 조용한 시간을 제공한다.
- 잠금화면 제목과 본문에는 생리, PMS, 주기 국면, 증상, 기분, 파트너 이름을 넣지 않는다.
- 기본 문구는 “사이클 페어에 확인할 새 소식이 있어요.”처럼 중립적으로 쓴다.
- 상세 건강정보는 앱 잠금 해제와 권한 확인 이후에만 표시한다.
- 앱이 열린 상태에서는 최초 동기화가 아닌 상대의 새 공유 기록과 공동 일정 변경만 인앱 토스트와 새 소식 메시지 박스로 알린다.

## Analytics 정책

- prefix는 cp_를 사용한다.
- 허용 이벤트: 온보딩 완료, 초대 발송, Pair 연결, 공유 설정 변경, 기록 완료, 파트너 화면 열기, 구독 완료.
- 이벤트에는 생리일, 증상, 기분, 메모, cyclePhase, 예정일, Pair ID, 상대 ID를 보내지 않는다.
- cp_cycle_log는 기록 성공 사실만 보내며 기록 내용은 보내지 않는다.
- cp_share_setting_update는 변경된 필드 이름이 아닌 개수만 보낼 수 있다.
- cp_care_tip_view의 phase 파라미터는 사용하지 않는다.
- 광고 식별자 기반 추적과 건강정보 기반 세분화는 금지한다.

## 수익화

- 광고는 사용하지 않는다.
- 다운로드는 무료다. 구독 기준 가격은 월 KRW 3,900, 연 KRW 29,000이며 다른 통화는 스토어 자동 환산을 사용한다. 두 상품 모두 7일 체험을 준비한다.
- MVP entitlement는 본인 기록, 기본 예측, 단일 상대 공유를 기본 후보로 둔다.
- 상세 예측, 전체 케어 콘텐츠, 확장 이력은 프리미엄 후보이나 출시 전 확정한다.
- multiple-connections 기능은 MVP entitlement로 활성화하지 않는다.

## 출시 전 남은 제품 결정

- `사이클 페어`와 `Cycle Pair`의 출시 전 최종 선행상표 검토. 초기 코드명 `MoonMate`는 주기·기분 기록과 파트너 공유를 제공하는 동명 앱이 App Store·Google Play에 이미 있어 폐기했다.
- 로그인 제공자
- 민감 건강정보 동의문 `2026-08-09-v1`의 사업·법률 검토 evidence
- Pair 감사로그·백업 삭제기간. 만료 invite는 `expiresAt` 후 7일, acknowledged cache tombstone은 `acknowledgedAt` 후 30일 보존으로 확정
- 앱 연령등급
- 최종 예측 설명 문구와 케어 콘텐츠 검수
