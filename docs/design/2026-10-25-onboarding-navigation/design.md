# 작은 기록, 더 가까운 우리

설계 v3, 2026-10-25. 승인된 설계를 React Native 화면에 적용한다. 승인 원본은 `4a7f9ee68cef39eee8662aaeee61de241140de4c`이며, 실제 실행과 독립 검수 결과는 별도로 기록한다. 사용자가 정한 전 세계 출시, 이메일 계정과 게스트, IAP 완전 제거, 후속 전면광고와 보상광고 계획을 반영한다. 이번 출시는 무료이며 광고를 표시하지 않는다. [조작 가능한 화면](preview.html)과 [테스트 계획](test-plan.json)을 함께 검토한다. 이전 소셜로그인 시안은 이 설계로 대체한다.

## 목적과 시각 방향

젊은 성인 커플이 자신을 살피고 원하는 기록만 나누는 공간이다. 파트너 연결 없이 혼자 사용하는 사람도 같은 기록 기능을 이용한다. 성별, 역할, 국적에 따라 기록 주체와 돌봄 주체를 고정하지 않는다.

크림색 바탕, 라벤더의 주요 행동, 세이지의 편안한 안내, 살구색의 강조를 기존 브랜드에서 이어간다. 큰 그림은 시작 화면에서 두 사람이 일상을 함께하는 모습을 설명한다. 입력과 오류 화면에서는 그림의 크기를 줄여 행동이 바로 보이게 한다. 제목은 문장 하나, 설명은 짧게 쓰고 낯선 아이콘에는 라벨을 붙인다. 본문은 대비를 확보한 짙은 자주색, 주요 버튼은 기존 라벤더보다 진한 `#5E4D96`을 쓴다.

일러스트는 따뜻한 과슈 질감의 원본 PNG, 아이콘 13종은 편집 가능한 SVG다. 그림에는 문자를 넣지 않아 한국어와 영어가 같은 원본을 쓴다. 시스템 글꼴과 글자 확대를 유지하며 이미지에 설명이나 필수 동의를 구워 넣지 않는다. [출처와 해시](assets/sources.json), [그림 제작 문구](assets/illustration-prompt.txt)를 기록한다.

## 화면별 목적

| 화면 | 끝낼 행동 | 시각 표현과 문구 |
| --- | --- | --- |
| 처음 시작 | 이메일 또는 게스트 선택 | 두 사람의 일러스트. ‘오늘의 나를, 조금 더 다정하게.’ / ‘A little space to understand each other.’ |
| 기록 목적 | 주기 포함 여부 선택 | 주기 아이콘과 잎 아이콘, ‘주기와 컨디션’ 또는 ‘컨디션만’. 선택 후 계속하기 |
| 건강 정보 동의 | 이용 범위를 읽고 동의 여부 선택 | 자물쇠와 공개 범위. 수집 항목과 목적, 보관과 계정 삭제 안내는 글로 그대로 표시 |
| 주기 시작 정보 | 날짜와 길이를 한 단계씩 선택 | 입력 하나와 단계 표시. 각각 ‘모르겠어요, 건너뛰기’ 제공 |
| 기록 사용법 | 한 번의 예시 확인 | ‘편안해요’, 짧은 메모, ‘나만 보기’가 들어간 예시 카드 |
| 선택 공유 | 연결 여부 선택 | 두 사람 아이콘, ‘각자의 기록, 선택한 만큼만’. 혼자 시작하기도 같은 높이의 버튼 |
| 오늘 | 오늘 기록 시작 또는 수정 | 일기 카드와 자물쇠, 7일의 기록 여부. ‘조금 느린 하루여도 괜찮아요.’ |
| 기록 | 지금의 마음과 선택 메모 저장 | 잎, 햇살, 달, 구름과 찻잔에 마음 라벨. 고르기 전엔 저장 비활성 |
| 나의 흐름 | 남긴 기록 돌아보기 | 기간과 기록 건수, 상태별 막대, 미기록 수. 데이터가 없으면 빈 일기 그림과 첫 기록 행동 |
| 파트너 | 연결 또는 선택 공유 확인 | 찻잔과 짧은 말, ‘오늘은 어떻게 함께하면 좋을까?’ 상대가 직접 공유한 기록만 표시 |

주간 보기의 빈 날은 실패나 나쁜 점수가 아니다. 연속 기록 경쟁, 연애 점수, 마음의 좋고 나쁨 평가, 기록으로 추측한 파트너 상태를 만들지 않는다. 현재 예시는 ‘설계용 예시’와 ‘예시 데이터’를 표시하며 실측 결과로 사용하지 않는다. 실제 앱의 시각화는 기존에 본인이 직접 기록한 값과 허용된 공유값만 쓴다. 예측에는 참고 범위와 표본 수를 함께 표시하고, 충분한 근거가 없으면 숫자와 그래프를 만들지 않는다. ‘10년 데이터’나 의학적 정확도를 약속하지 않는다.

## 시작 흐름과 계정

이메일 계정과 게스트는 모두 기록 목적 질문으로 연결한다. 주기가 필요하면 건강 정보 동의 뒤 날짜와 길이를 선택하고, 컨디션만 필요하면 생리 질문 없이 기록 사용법으로 간다. 다음은 선택 공유 안내다. 주기 분기는 초대 방법, 컨디션 분기는 받은 코드 입력을 먼저 제안하되 두 방식 모두 나중에 변경할 수 있다.

이미 온보딩을 마친 이메일 계정은 기록을 복구해 홈으로, 완료 전 앱을 종료한 계정은 목적 선택부터 재시작한다. 미저장 민감 초안은 서버나 일반 저장소에 남기지 않는다. 이미 시작한 게스트에게 매번 가입을 요구하지 않는다. 이후 이메일 계정 연결은 같은 UID와 기록, 파트너 연결을 유지하며 온보딩을 반복하지 않는다. 계정 충돌은 자동 병합하지 않는다. 구체적 경계는 [계정 설계](account-design.md)에 둔다.

주기와 컨디션 이용 동의, 파트너 공유는 별개다. 로그인만으로 건강 정보 동의나 파트너 공개가 이루어지지 않는다. 공유 항목은 모두 끈 상태로 시작하고 사용자가 직접 켠 항목만 전달한다. 법적 고지 원문과 개인정보 처리방침은 감성 문구로 대체하지 않는다. 최소 연령은 기존 정책의 만 17세 이상을 유지한다. 별도 건강 정보 동의 철회 설정을 약속하지 않고 실제 계정 삭제와 항목별 공유 해제 행동을 안내한다. 동의 화면의 최종 문구는 기존 운영 처리방침과 데이터 계약에 맞춰 검수한다.

## 뒤로 이동과 상태

현재 구현의 저장 중 이탈 차단과 설정, 초대 초안 보존은 별도 버그 수정 PR #154로 처리한다. 새 온보딩도 이전 이동에 날짜와 길이, 선택을 보존한다. 기록 목적을 바꿔도 입력을 서버에 먼저 보내지 않고, 컨디션만 선택했을 때 주기 초안은 저장하지 않는다. 제출 중에는 중복 저장을 막고 실패 후 재시도와 초안을 유지한다. 앱 재실행 후 민감한 초안을 일반 로컬 저장소에 쓰지 않는다.

빈 상태는 이유와 시작 행동, 로딩은 진행 상태, 오류는 복구 행동, 저장 완료는 실제 저장 확인 뒤 표시한다. 오프라인 대기 저장과 서버 저장 완료를 구분한다. 건강 동의와 공유 선택 변경 실패 시 성공을 표시하지 않는다.

## 구조와 접근성

기존 RN, 계정 경계와 Firebase 저장 계약을 사용한다. 제품 코어는 이미지와 UI 라이브러리를 참조하지 않는다. 사용자별 React 트리와 보안 저장소를 유지한다. 첫 출시에서 소셜 SDK, 광고 SDK와 새 결제 SDK를 추가하지 않는다. SVG는 원본으로 유지하고, 실제 RN 적용 때 현재 지원 이미지 형식으로 만들어 같은 아이콘 체계를 사용한다. 새 벡터 SDK 도입은 이 시안에 포함하지 않는다.

320px 화면과 글자 200%에서 버튼을 자르지 않는다. 버튼은 최소 높이 48px, 입력은 키보드 위에서 끝낼 수 있게 한다. 그림과 장식 아이콘은 화면 읽기에서 제외하고 버튼 이름, 선택 상태와 오류를 읽는다. 그래프에는 기간과 단위, 범례와 텍스트 요약을 제공한다. 색깔만으로 의미를 전달하지 않는다. 불필요한 애니메이션과 강제 가로 스크롤은 넣지 않는다.

## 검수와 적용

L3 개발 환경 전체 회귀와 실제 RN 화면의 독립 검수 3회를 계획한다. 매 회차 전에 고정 후보, 환경, 격리된 가상 자료와 기대 결과를 기록한다. 첫 회차는 한국어 320px과 핵심 흐름, 둘째는 영어와 200% 글자, 셋째는 오류와 복구, 장기간 기록과 계정 경계까지 모두 다시 확인한다. 각 회차가 기능과 사용성을 모두 확인하며 작성자의 HTML 확인을 독립 검수로 세지 않는다. 최초 네이티브 인증과 알림 등 기기로만 확인할 필수 항목은 개발 검사 뒤 따로 소명한다. 현재 기기 사용 승인은 없다.

사용자가 승인한 이 시안과 테스트 계획에 따라 RN 화면을 구현한다. 새 버전 번호와 태그는 아직 정하지 않았다. Google Play와 App Store는 글로벌 공개까지의 기존 출시 범위를 유지하되, 변경 후 실제 화면으로 등록 이미지를 다시 만든다. 기존 빌드 업로드, 심사와 공개를 새로운 코드의 완료로 표시하지 않는다. 복구는 화면 코드 되돌리기이며 기존 계정이나 기록 삭제를 요구하지 않는다.
