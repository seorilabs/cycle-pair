# 첫 출시 계정 범위

사용자가 이메일 계정과 게스트로 먼저 출시하고 소셜로그인을 후속으로 미루기로 선택했다. Apple, Google, 카카오와 네이버 버튼, 인증 SDK와 개발자 등록은 이번 출시 범위에서 제외한다. 이전 시안의 미사용 로고와 가짜 소셜 인증 선택기도 제거했다.

계정의 목적은 재설치와 기기 변경 후 기록과 파트너 연결 복구다. 이메일 계정이 이를 제공한다. 처음 시작 화면의 ‘이메일로 시작하기’와 ‘계정 없이 시작하기’를 모두 바로 볼 수 있게 한다. 이메일 로그인과 가입, 비밀번호 재설정은 현재 계정 경계를 사용하고, 실제 인증 결과가 확인된 뒤 다음 단계로 이동한다. 인증 취소와 실패는 기존 기록이나 계정을 변경하지 않는다.

신규 이메일 계정과 게스트는 같은 기록 목적 온보딩으로 간다. 이미 완료한 계정은 기록을 복구한 홈으로, 미완료 계정은 이어할 단계로 간다. 게스트가 나중에 이메일을 연결하면 기존 Firebase UID, 현재 기록과 파트너 연결을 유지하고 온보딩을 반복하지 않는다. 이미 쓰는 이메일과 충돌하면 자동 병합하지 않고 현재 기록을 보존한다. 로그아웃과 다른 계정 복구 시 기존 계정별 캐시 경계를 유지한다.

건강 정보 동의는 인증 동의와 별개이고, 파트너 공유는 기본 비공개다. 지원 코드와 문의, 내보내기와 계정 삭제는 결제와 무관하게 유지한다.

후속 소셜로그인을 다시 진행할 때의 확정 조건은 카카오를 기기의 국가 또는 지역 설정이 KR일 때만 표시하는 것이다. 앱 언어, IP와 GPS는 기준이 아니다. 지역이 미확인인 경우 숨긴다. 사용자가 기존 Cycle Pair 전용 OAuth 등록이 없다고 확인했다. 현재 새 앱, 클라이언트와 비밀값은 만들지 않았다.
