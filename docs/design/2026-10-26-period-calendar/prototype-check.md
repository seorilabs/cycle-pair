# 달력 시안 작성자 확인

공식 사용 안내 기반 벤치마크와 조작 가능한 HTML 시안을 작성했다. 실제 RN 달력 구현과 제품 회귀는 아직 실행하지 않았다.

처음 시안에서는 달력 아래의 생리 기록 버튼에 도달하려면 스크롤해야 했다. 선택 날짜와 기록 버튼을 화면 아래에 고정하고 글자 200%의 편집창도 저장 버튼이 보이도록 고쳤다. 초기 작성자 화면도 후속 화면과 함께 보존했으며 독립 제품 검수 회차로 세지 않았다.

- 마지막 시안은 실제 달력 영역 폭 320px, 한국어와 영어, 글자 100%와 200%, 컬러와 흑백, 네 선택 날짜의 32가지 조합에서 가로 넘침, 미래 날짜의 실제 기록 차단과 고정 기록 버튼을 확인했다.
- 날짜별 편집, 시작과 종료를 함께 켜는 하루 기록, 표시 해제 후 메모 보존, 월 이동과 오늘 복귀, 큰 글자에서 편집창의 저장과 닫기를 조작했다.
- 기본 달력, 큰 글자 흑백, 편집창과 이력의 한국어 및 영어 화면을 검토했다. 예측과 평균은 고정된 설계 예시이며 제품의 계산 검증이 아니다.
- 테스트 계획을 현재 중앙 JSON Schema로 확인했다. 제품 구현과 3회 독립 화면 검수의 근거로 대신 쓰지 않는다.
