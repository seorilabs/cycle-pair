# IAP와 구독 모델 제거

사용자가 2026-10-25에 IAP BM을 전부 제거하도록 지시했다. 전 세계 Google Play와 App Store 출시는 유지한다. 이번 출시는 무료이며 광고 SDK도 넣지 않는다. 전면광고와 보상광고는 후속 제품 결정으로 남긴다.

## 범위와 동작

클라이언트의 구매 어댑터, 구독 컨텍스트와 상품 목록, 제품 코어의 구매 계약과 권한 계산, Firebase의 구매 확인과 스토어 알림 처리, Apple 영수증 및 Google Publisher SDK 의존성을 제거한다. 계정 연결, 지원 코드와 계정 복구는 결제와 무관하게 유지한다. 결제 상태에 따른 기능 제한을 없애고 실제 기록에 근거한 예측 설명과 맞춤 돌봄 팁을 모든 계정에 제공한다. 예측은 현재 제품의 최근 365일 조회 범위로 통일하며 데이터 보유 기간이나 10년 정확도를 약속하지 않는다. 기록이 없으면 근거 없음 상태를 유지한다.

서버 배포는 별도 출시 후보의 검증 뒤에 수행한다. 삭제된 함수의 운영 인스턴스, 스토어 상품, 비밀값과 공통 플랫폼 서비스는 이 코드 변경으로 삭제하지 않는다. 운영 금융 자료의 존재 여부를 확인하지 않았으므로 과거 자료는 일괄 삭제하지 않는다. 기존 계정 삭제 계약에 포함된 과거 구매 자료 정리만 유지하며 활성 구매 처리나 권한 부여에는 사용하지 않는다. 해당 경로의 클라이언트 읽기 권한도 제거한다.

## 구조와 실패

화면은 구독 Provider 없이 기존 계정별 제품 Provider를 사용한다. 계정의 UID 키를 보존해 다른 계정으로의 초안 노출을 막는다. 결제 호출이나 권한 갱신 실패가 제품 진입을 막는 분기는 없어지고, 기존 기록 저장과 동기화의 오류 처리는 유지한다. 출시 검증의 구독 상품 일치 검사도 제거하고 무료 및 무광고 설정을 유지한다.

## 인수조건과 검증

구매, 구매 복원, 구독 상태 조회와 알림 처리 진입점이 제품 소스에서 사라진다. 모든 계정에서 동일한 기록 기반 기능을 제공하고 예측 근거가 없는 경우 수치를 만들지 않는다. 건강 동의와 선택 공유, 계정 삭제와 자료 내보내기는 기존 검사를 유지한다. 먼저 무료 사용자의 팁과 예측 설명이 누락되는 실제 회귀 검사를 확인하고 변경한다.

L3 개발 환경 전체 회귀를 다른 실행자 또는 확인된 CI로 수행한다. 화면 개편은 별도 설계이며 이번 변경은 기존 화면 배치 유지다. 기기를 조회하거나 조작하지 않는다. 기존 첫 출시 네이티브 검증을 통과로 바꾸지 않는다. 복구는 코드 되돌리기이며 사용자 자료 초기화가 필요하지 않다.
