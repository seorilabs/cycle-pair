# Play 데이터 보안 CSV 입력 복구

사용자가 2026-10-25 검토한 데이터 보안 답안을 Console에 저장하도록 승인했다. 현재 1.1.1(1000108), 소스 f450f62의 AAB는 내부 테스터에게 제공 중이다. 기존 CSV는 현재 Console에서 `PSL_SUPPORTED_ACCOUNT_CREATION_METHODS` 응답 누락으로 거절됐다.

현재 Console의 공식 샘플 양식에 맞춰 생성기에 이메일과 비밀번호 가입, 익명 게스트 가입, 계정 삭제 링크와 개별 기록 삭제 지원을 넣는다. 신규 수집 자료나 공유 목적은 추가하지 않는다. 사용자가 승인한 10개 자료 분류, 필수와 선택 여부, 수집 목적을 그대로 유지한다.

현재 양식은 계정 삭제 링크 외에 `PSL_DATA_DELETION_URL`도 요구한다. 기존 한국어와 영어 삭제 안내에 실제 앱의 달력에서 개별 기록을 삭제하는 절차를 추가하고 게시를 확인한다. 계정을 유지하는 삭제 안내의 앵커 주소를 입력하며, 전체 계정 삭제 절차로 대신하지 않는다. 개별 기록 삭제 후 주기 설정의 시작과 종료 기준이 유지되는 동작도 안내한다.

검증은 누락 응답을 재현한 실패 테스트, 생성기 회귀, 실제 Console 가져오기와 최종 저장 뒤 재내보내기 대조로 한다. 계정 방식이 없거나 현재 양식에 없는 선택값이면 생성 단계에서 중단한다. 네이티브 코드와 앱 후보는 바꾸지 않으며 이 수정으로 기기 검수와 독립 화면 검수 회차를 추가하지 않는다. 이미 통과한 앱의 전체 회귀와 화면 검수 3회는 원래 후보의 증거로 보존한다.

이번 변경은 마켓 신고 생성기와 신고 자료만 대상으로 한다. 내부 테스트 AAB의 태그를 이동하지 않고, 기기 사용과 공개 심사 제출을 포함하지 않는다. Console 답안의 저장, Google 검토와 공개는 따로 기록한다.

실행 결과: 생성기 회귀 199개와 실제 CSV 가져오기를 통과했다. Console 임시 저장 뒤 페이지를 다시 열고 내보낸 CSV에서 수집 분류 10개와 목적, 필수 여부, 임시 처리 여부, 암호화와 삭제 URL을 대조했다. 모두 일치했다. 최종 완료 버튼은 타겟층 선행 설정에 막혀 있으므로 완료로 표시하지 않는다. 타겟층 설정은 심사용 로그인 안내의 완료를 먼저 요구한다. 관련 작업은 #145이며 최종 완료 전까지 열어 둔다.
