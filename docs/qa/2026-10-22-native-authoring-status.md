# 네이티브 출시 구현 중간 기록

2026-10-22의 작성자 구현과 실행 기록이다. 현재 소스는 작업 브랜치의 변경 상태이며, 공식 L3 또는 독립 UI 검수 통과 근거로 사용하지 않는다. 기준 설계 커밋은 `d12718895c53c713b6174d7b51b3db09d4d06f39`이다.

## 변경

- 앱인토스 앱과 전용 의존성, 배포 작업을 제거했다. 외부 콘솔은 변경하지 않았다.
- 신규 결제 초기화와 Plus 판매 화면을 제외했다. 서버 상품과 구독 자료는 유지했다.
- 첫 안내, 홈, 기록, 파트너, 초대, 공유, 달력과 설정을 승인 설계에 따라 개편하고 한국어와 영어, 시스템 기본 언어와 수동 선택을 지원했다.
- 로컬 Firebase와 운영 서비스의 개발 실행을 분리하고 출시 번들의 Emulator 선택을 거부한다. 두 네이티브 마켓과 단계별 출시 검사, 실제 화면 입력 실행기를 추가했다.

## 발견과 수정

| 항목 | 실제 실패와 원인 | 수정과 재확인 |
|---|---|---|

| iOS 키보드 | 저장 위치에서 키보드 글자가 입력됐다. InputAccessoryView는 이 구성에서 노출되지 않았다. | 화면이 키보드 높이를 피하고 닫기 버튼을 제공한다. 실제 iOS 닫기와 저장을 확인했다. |
| 재실행 직후 편집 | 캐시와 원격 기록을 읽기 전에 빈 초안을 열 수 있었다. | 오늘 캐시 또는 원격 복원 완료까지 편집을 잠그고 오류 재시도를 제공한다. 지연 복원 테스트2개와 Android 원문 재실행 복원이 통과했다. |
| 공유 미리보기 | 날짜 정보가 빠져 오래된 자료를 숨기는 표시 함수가 선택값을 제거했다. | 서버와 같은 날짜 규약을 포함했다. 2048가지 공유 조합과 실제 표시값 테스트, Android 미리보기 및 iOS 상대 표시를 확인했다. |
| 공유 화면 유지 | 저장된 설정의 실시간 갱신이 편집 중인 화면을 닫았다. | 기존 설정 편집은 유지하고 초기 복원은 홈으로 간다. 실패 테스트 후 통과, 실제 선택 공유가 통과했다. |
| 로컬 내보내기 | Emulator가 운영 HTTPS 주소를 만들었다. | 로컬 주소와 운영 HTTPS 검사를 분리했다. 서버 및 모바일 경계 테스트가 통과했다. 실제 계정 내보내기 UI는 미실행이다. |
| iOS 암호화 저장 | RNKeychain10.0.0이 false를 참으로 처리해 기존 캐시를 기본 읽기에서 찾지 못했다. | [라이브러리 패치와 원문 보존 이관](../design/2026-10-22-native-launch/keychain-repair.md)을 작성했다. 적용은 사용자 확인 대기다. |

## 실행 근거

비공개 원본 루트: `~/.local/share/seorilabs/cycle-pair-qa/2026-10-22`.

- `authoring-android-10`: 네트워크 차단 확인 후 오프라인 저장, 앱 재실행과 원문 복원, 온라인 복귀 후 동기화 통과.
- `authoring-android-13`: 감정과 도움 선택, 메모 교체와 저장, 앱 재실행, 달력 원문 확인 통과. 공유 시도 원본 실패도 보존했다.
- `authoring-pair-01`: 화면에서 초대를 생성하고 코드를 메모리로 전달해 수락했다. 서버는 accepted와 active 상태였고, 화면 검사에서 미리보기까지 스크롤하지 않아 전체 여정은 실패했다.
- `authoring-pair-02`: 기본 비공개 확인은 통과했다. 표시 미리보기 결함을 보존했다.
- `authoring-pair-03`: 선택 공유, 상대의 감정과 도움 표시, 비공개 메모 숨김 통과. 공동 일정 입력의 키보드 닫기 뒤 실패는 그대로 보존했다.
- `authoring-pair-05`: 공동 일정 생성과 상대 표시, 공유 회수와 상대 재실행 확인, 연결 해제와 해제 후 재실행6개 여정이 통과했다. 일정 저장은 실제 화면의 저장 버튼으로 실행했고 이전 키보드 조작 실패는 보존했다.
- 이 기록들은 작성자 실행이고 `sourceDirty: true`다. 독립 검수 회차는0회다. 실행기 `passed: false`와 미실행 목록을 유지한다.

Android16은 기존 이미지를 재사용한 소유 AVD다. 최초 OS 응답 오류와 복구 기록을 보존했고, 실제 할당량은8GB 한도 안이다. iOS18.1 전용 Simulator와 양쪽 Debug1.1.0(1001000)을 사용했다. 물리 기기는 조회하거나 사용하지 않았다.

## 남은 조건

iOS 저장 패치의 승인, 적용과 실제 재빌드가 먼저 필요하다. 계정 복구와 내보내기, 삭제, 초대 만료와 재사용, 원격 푸시, 큰 글자와 화면 읽기, 운영 서비스의 두 사용자 실행이 아직 완료되지 않았다. 승인 후보에서 독립 L3와 UI3, 로컬 코드 리뷰, CI와 PR, 중앙 출시 검증기를 통과해야 한다. 새 실제 스크린샷, 정책과 심사 정보, 두 마켓 업로드와 제출, 승인, 공개 및 live 확인은 별도 미완료 단계다.

검수 대기 중 소유 AVD와 Simulator는 종료하고 사용자 자료와 iOS Keychain 원본을 보존했다. Metro와 개발 Firebase도 종료했으며 로컬 합성 자료는 소유 표식이 있는 비공개 Emulator 스냅샷으로 내보냈다. 실행기가 만든 임시 `.env.local`과 `.secret.local`만 정상 정리됐고 운영 자격증명은 바꾸지 않았다.

최종 정적 확인에서 `pnpm test`가 통과했다. 플랫폼 SDK 검사15개, 핵심68개, 모바일337개, 서버99개, 보안 규칙24개, Functions Emulator 통합5개와 출시 검사64개다. 모바일337개에는 아직 적용하지 않은 저장 이관 제안의 단위 테스트6개가 포함된다. 전체 타입 검사, lint와 `git diff --check`도 통과했다. 이 결과는 작성자 자동 검사이며 승인 후보의 독립 L3를 대신하지 않는다.
